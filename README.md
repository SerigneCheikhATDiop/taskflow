# TaskFlow Teams : J1 (maquette statique)

Kanban d'équipe en React 19 + TypeScript + Vite + Tailwind v4.

## Installation

    npm install
    npm run dev

## Capture d'écran

![Board TaskFlow](docs/board.png)

## Ce qui est fait au J1
- Board statique avec 3 colonnes (À faire, En cours, Terminé)
- 8 tâches mockées
- Composants : Header, Board, Column, TaskCard, PriorityBadge
- Badge « En retard » et message « Aucune tâche »
